Kseniia – Ohjelmistokehittäjä

Rakennan selkeitä, toimivia ja käyttäjäystävällisiä sovelluksia.

Minusta

Olen Kseniia, ohjelmistokehittäjä, joka nauttii ongelmanratkaisusta, rauhallisesta työskentelystä ja selkeästä dokumentoinnista. Pidän siitä, että koodi on ymmärrettävää ja helposti ylläpidettävää.

Tavoitteeni on kehittyä monipuoliseksi kehittäjäksi, joka hallitsee modernit työkalut ja pystyy rakentamaan sekä pieniä että laajempia projekteja.

Osaaminen

Frontend-kehitys

Rakennan selkeitä ja responsiivisia käyttöliittymiä HTML:n ja CSS:n avulla. Keskityn siihen, että sivut toimivat hyvin sekä puhelimella että tietokoneella.

  • HTML
  • CSS
  • Responsiivinen suunnittelu
  • Käyttöliittymän selkeys

Backend-perusteet

Teen pieniä harjoitusprojekteja Pythonilla, kuten botteja ja automaatioita. Tavoitteena on oppia rakentamaan yksinkertaisia palveluita ja käsittelemään dataa.

  • Python
  • Automaatio
  • Pienet skriptit

Versionhallinta

Käytän Git-versionhallintaa projektien hallintaan ja GitHubia projektien julkaisuun sekä dokumentointiin.

  • Git
  • GitHub
  • GitHub Pages

Dokumentointi ja suunnittelu

Kirjoitan selkeitä ohjeita ja projektikuvauksia Markdownilla. Suunnittelen projektit vaiheittain ja dokumentoin oppimisen.

  • Markdown
  • Projektisuunnittelu
  • Selkeä dokumentointi

Projektit

Portfolio GitHub Pagesissa

Tämä sivu toimii ohjelmistokehittäjän portfoliosivuna. Se on rakennettu HTML:llä ja CSS:llä ja julkaistu GitHub Pagesissa.

Tekniikat: HTML, CSS, Git, GitHub Pages

Python Botit

Olen tehnyt pieniä Python-botteja, jotka suorittavat automaattisia tehtäviä, kuten tiedostojen käsittelyä tai yksinkertaisia komentoja.

Tekniikat: Python, automaatio

Harjoitussivustot

Rakennan harjoitussivustoja HTML:llä ja CSS:llä oppiakseni rakenteen, typografian ja ulkoasun hallintaa.

Tekniikat: HTML, CSS
